TITLOVI BEZ REKLAMA
===================

Kratki opis za forum
--------------------

Titlovi Bez Reklama je mali program za automatsko čišćenje .srt titlova.
Program prolazi kroz odabrani folder, pronalazi .srt datoteke i uklanja blokove
titlova koji sadrže reklame, potpise prevoditelja ili promotivni tekst.

Program automatski renumerira titlove nakon uklanjanja blokova i može napraviti
backup originalnih datoteka s nastavkom .srt.bak.


Glavne mogućnosti
-----------------

- Grafičko sučelje.
- Radi s .srt titlovima.
- Pretražuje odabrani folder i podfoldere.
- Uklanja reklamne i promotivne blokove prema ključnim riječima.
- Ključne riječi se mogu ručno mijenjati u programu.
- Može napraviti backup originalnih titlova.
- Prikazuje statistiku obrade.
- Ima hrvatski i engleski jezik sučelja.
- Python verzija radi na Linuxu.
- Na Windowsima se može napraviti .exe datoteka pomoću PyInstallera.


Datoteke u ovom folderu
-----------------------

titlovi_bez_reklama.py
Glavna Python datoteka. Nju pokrećeš na Linuxu ili koristiš kao izvor za izradu
Windows .exe datoteke.

pokreni_titlovi_bez_reklama.bat
Windows skripta za pokretanje programa iz izvornog Python koda.

pokreni_titlovi_bez_reklama.sh
Linux/macOS skripta za pokretanje programa iz izvornog Python koda.

titlovi_bez_reklama.spec
PyInstaller konfiguracija za izradu Windows .exe datoteke.

build_windows_exe.bat
Windows skripta koja izrađuje .exe datoteku. Pokreće se na Windowsima.

Titlovi Bez Reklama.txt
Detaljnije upute za korisnika.

arhiva/
Folder sa starim build datotekama. To su stare verzije .exe i .zip datoteka.


Pokretanje na Windowsu
----------------------

1. Instaliraj Python za Windows.
2. Kod instalacije uključi opciju "Add Python to PATH".
3. Dvaput klikni:

   pokreni_titlovi_bez_reklama.bat


Pokretanje na Linuxu
--------------------

1. Otvori terminal u folderu programa.
2. Pokreni:

   ./pokreni_titlovi_bez_reklama.sh

Možeš pokrenuti i direktno:

   python3 titlovi_bez_reklama.py

Ako Linux javi da nema Tkinter, instaliraj ga:

Ubuntu/Debian:
   sudo apt install python3-tk

Fedora:
   sudo dnf install python3-tkinter

Arch:
   sudo pacman -S tk


Korištenje programa
-------------------

1. Pokreni program.
2. Klikni "Odaberi Folder".
3. Odaberi folder u kojem se nalaze .srt titlovi.
4. Po želji provjeri ili promijeni ključne riječi za filtriranje.
5. Ostavi uključenu opciju za backup ako želiš sačuvati originale.
6. Klikni "Pokreni Čišćenje".
7. Nakon obrade provjeri statistiku i dnevnik obrade.

Ako je backup uključen, originalna datoteka ostaje spremljena kao:

   film.srt.bak

a očišćena verzija ostaje kao:

   film.srt


Izrada Windows .exe datoteke
----------------------------

Ovo radiš tek kad budeš na Windowsima.

1. Instaliraj Python za Windows.
2. Kod instalacije uključi opciju "Add Python to PATH".
3. Otvori folder programa.
4. Pokreni:

   build_windows_exe.bat

Skripta će provjeriti postoji li PyInstaller. Ako ne postoji, pokušat će ga
instalirati automatski.

Nakon uspješnog builda, gotova datoteka bit će ovdje:

   dist\Titlovi Bez Reklama.exe


Napomena
--------

Prije masovne obrade preporučljivo je testirati program na kopiji nekoliko
titlova. Ključne riječi treba držati dovoljno preciznima da program ne ukloni
normalne dijelove dijaloga.
